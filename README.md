# Checklist AISVS Bahasa Indonesia

Checklist verifikasi keamanan aplikasi AI berdasarkan OWASP AISVS v1.01. Repositori ini memuat adaptasi bahasa Indonesia yang telah ditinjau, laporan verifikasi, dan presentasi untuk pembaca umum.

## Berkas

- [Checklist Excel](OWASP-AISVS-v1.01-Checklist-ID.xlsx) memuat 282 kontrol AISVS dan 20 item verifikasi pelengkap.
- [Laporan review](Hasil-Review-AISVS-v1.01.md) mencatat pemetaan sumber, temuan, perbaikan, dan hasil verifikasi ulang.
- [Presentasi PDF v1.02](Presentasi-Checklist-AISVS-v1.02-ID.pdf) adalah versi presentasi terbaru. Checklist Excel dan laporan review di repositori ini menggunakan AISVS v1.01.

## Cara menggunakan checklist

1. Tetapkan fitur, data, dan tindakan AI yang masuk dalam cakupan.
2. Buka tab **Checklist Pengujian** dan filter kontrol berdasarkan bab dan level.
3. Catat status dan bukti per ID. Gunakan tab **Verifikasi Tambahan** untuk 20 item pelengkap.
4. Simpan bukti asesmen sensitif di penyimpanan internal yang sesuai.
